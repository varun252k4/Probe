# Install And Deploy Probe

This document covers local installation, package creation, and Microsoft Edge
Add-ons deployment. The public store listing can replace the local installation
steps once Probe is published.

## Install Locally In Microsoft Edge

1. Download or clone this repository.
2. Open `edge://extensions` in Microsoft Edge.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the repository folder containing `manifest.json`.
6. Open or refresh [ChatGPT](https://chatgpt.com/) or your Open WebUI instance.

Probe is now ready. Select text in a supported assistant response and choose
**Ask with Probe**.

## Update A Local Installation

1. Download or pull the latest source.
2. Open `edge://extensions`.
3. Find Probe and select **Reload**.
4. Refresh any open ChatGPT pages.

## Build An Edge Package

The local packaging script creates a ZIP whose root contains `manifest.json`:

```powershell
.\scripts\package.ps1
```

The output is written to `dist/probe-edge-v<version>.zip`. Both `dist/` and the
PowerShell packaging script are intentionally excluded from Git.

## Publish To Microsoft Edge Add-ons

1. Create a Microsoft Partner Center account and open the Edge Add-ons
   dashboard.
2. Create a new extension submission.
3. Upload the ZIP generated by the packaging script.
4. Add the product description, screenshots, icons, support details, and
   privacy-policy URL requested by Partner Center.
5. Declare the locally stored history and the selected ChatGPT content used to
   provide contextual answers.
6. Complete the availability and certification sections, then submit the
   extension for review.

For each release, update the `version` in `manifest.json`, rebuild the ZIP, and
upload the newly generated package.

## Troubleshooting

- If **Ask with Probe** does not appear, select text from a ChatGPT answer, not
  from your own prompt.
- Refresh ChatGPT or Open WebUI after installing, updating, or reloading the extension.
- Sign in to the provider before using Probe.
- Keep the Probe card open when asking related follow-up questions.
- Close and reopen the card if a Temporary Chat response stalls.
- For Open WebUI, set a model override in Probe settings if Probe cannot infer
   the selected model from the page.

## Supported Pages

- `https://chatgpt.com/*`
- `https://chat.openai.com/*`
- Custom-hosted Open WebUI domains detected at runtime.
